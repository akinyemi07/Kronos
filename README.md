# Kronos

**Learn it. Practise it. Prove it.**

Kronos is a hands-on engineering learning platform built around
real exercises in isolated environments.

## Initial scope

- Linux command-line labs
- Git practice
- Go and Python coding exercises
- Automated verification
- Learner progress tracking

## Safety

Labs must run in isolated environments.
Learner commands must never execute directly on the host.

## Current milestone

Prove that a disposable Linux environment can execute a lab
and return its results safely.
