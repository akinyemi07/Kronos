# Linux Lab 001: Time Zones

## Objective

Inspect time-zone configuration and understand system clock
synchronization.

## Tasks

1. Inspect the current time and time zone.
2. Find available time zones.
3. Explain the difference between UTC and local time.
4. Identify how NTP synchronization is checked.
5. Explain why changing a time zone does not synchronize a clock.

## Environment

Start with safe, read-only exercises in a disposable Linux
container. System time-zone changes and NTP service management
require a suitable environment in a later version.
